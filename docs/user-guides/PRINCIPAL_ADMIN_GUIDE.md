# Principal and Administrator Guide

## Daily start

1. Open the dashboard and confirm the correct school and role.
2. Open **Security & Backup → System readiness** and run checks.
3. Review the **Approval Inbox** for messages, leave, expenses, concessions and payroll.
4. Confirm attendance registers are being submitted.
5. Review failed/pending WhatsApp messages before approving bulk communication.

## Staff access

Use **Access Control** to create each staff member's individual account. Assign only job-required roles. Newly created users must replace their temporary password. Suspend departed staff immediately; never share the principal account.

## Academic cycle

Configure the academic year, grades, sections, subjects and teaching assignments before admissions. Review timetable conflicts before publication. Publish examinations only after all assessment components contain marks. Review result cards, then prepare and complete promotion runs. Completed promotion runs are locked.

## Sensitive approvals

Check evidence before approving expenses, fee concessions, payment reversals, leave, payroll or messages. Approvals create audit records. Never delete financial history to correct a mistake—use the controlled reversal workflow.

## WhatsApp

Use a dedicated school number. Scan QR only on the trusted host. Review consent and opt-outs. Automatic messages still obey quiet hours and the retry policy. If the connector disconnects, relink it; do not repeatedly send the same bulk campaign.

## Backups

Confirm a completed encrypted backup exists daily. Periodically copy encrypted backups to a separate drive/cloud location. Test restoration during a planned maintenance window. Stop the web server and workers before restoring.
